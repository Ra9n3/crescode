# Crescode — Phase 4.3C Listening Evaluation

Rate each progression on a 1–5 scale (1 = clearly poor, 5 = clearly strong).
These are HUMAN listening ratings — no generator-derived score belongs here.

Consistent listening conditions: use the exported audition MIDI files (same tempo,
same block-chord voicing, same velocity, same phrase boundaries) or any player at
the same volume. Rate configs A/B/C of the same cell+seed back to back.

| Dimension | Question |
|---|---|
| Tonal identity | Does the progression establish the intended tonal center? |
| Harmonic movement | Do chord changes feel natural and purposeful? |
| Phrase coherence | Does the progression feel like a connected musical idea? |
| Cadential quality | Do phrase endings feel appropriate? |
| Chromatic coherence | Do chromatic chords feel intentional rather than arbitrary? |
| Overall usefulness | Would a composer keep or develop this progression? |
